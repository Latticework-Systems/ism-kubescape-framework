# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email **tim@latticeworksystems.com.au** with the affected version or commit, the relevant file or workflow, reproduction steps, likely impact, and any suggested mitigation. Do not include credentials, customer data, kubeconfigs, tokens, or other sensitive material in the report.

Maintainers will acknowledge the report by email and coordinate disclosure after a fix is available.

## Supported versions

Until the first stable release, security fixes are applied to the latest release and the default branch only.
